# Политика конфиденциальности — Hermes

Владелец: частное лицо (личный проект)
Дата: 28 сентября 2026

Приложение «Hermes» — персональный ассистент, используемый одним владельцем
для личных задач. Это не публичный сервис и не предназначен для других
пользователей.

Какие данные обрабатываются:
- Gmail — чтение входящих писем от брокерских рассылок и личного адреса
  владельца, а также их вложений; после обработки письмо помечается
  прочитанным и перемещается в «Корзину».
- Google Календарь — чтение и создание событий.
- Google Tasks — чтение и создание задач.
- Google Таблицы и Google Диск — только чтение.

Как используются данные:
Исключительно для личного использования владельцем: получение брокерских
отчётов, ведение календаря, задач и учётных таблиц. Данные не продаются,
не передаются третьим лицам, не используются для рекламы и не используются
для обучения моделей.

Где хранятся данные:
На личном сервере владельца. Вложения сохраняются в локальную папку, токены
доступа — локально с ограниченным доступом. Внешним получателям данные
не передаются.

Удаление данных и отзыв доступа:
Доступ можно отозвать в любой момент на https://myaccount.google.com/permissions
После отзыва приложение теряет доступ, локально сохранённые данные удаляются
по запросу.

Контакт: владелец приложения (адрес поддержки указан на экране согласия Google)
